\# Mini Research Assistant



A command-line tool that searches the web using DuckDuckGo's free API and generates an AI-powered summary using Google Gemini API.



\## Features

\- Free, no-key web search via DuckDuckGo

\- AI-generated summaries using Gemini (gemini-3.5-flash-lite)

\- Color-coded terminal output



\## Setup

1\. Install dependencies: `pip install -r requirements.txt`

2\. Get a free Gemini API key at https://aistudio.google.com

3\. Set it as an environment variable: `setx GEMINI\_API\_KEY "your-key-here"`

4\. Run: `python search\_assistant.py "your question here"`



\## DuckDuckGo
- Used DuckDuckGo as it is free API (without key) giving instant results.

\## Gemini AI Summary
- Used Gemini 3.5-flash-lite API to perform AI summarization.
